# WPrint Artes Gráficas — site

Site estático (HTML + CSS + JS, sem build). Abra `index.html` ou publique em qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).

- **Produtos e opções:** edite o array `PRODUTOS` em `assets/js/app.js`.
- **WhatsApp:** constante `WHATSAPP` em `assets/js/app.js`.
- **Logo:** `assets/logo/` (símbolo, versão clara e versão para fundo escuro).

## Paleta

| Cor | Hex | Uso |
|---|---|---|
| Tinta | `#0E0E14` | fundo escuro, textos |
| Papel | `#F7F5F0` | fundo claro |
| Magenta | `#E5197A` | destaque principal, botões |
| Ciano | `#00A6D6` | acento |
| Amarelo | `#FFC21A` | acento |
